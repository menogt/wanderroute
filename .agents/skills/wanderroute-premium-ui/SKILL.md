# WanderRoute Premium UI

WanderRoute should feel like a premium digital Sri Lanka travel atlas rather than a generic AI application.

## Product character

The experience should communicate:

* Sri Lanka
* exploration
* practical travel planning
* real budgets
* real routes
* local knowledge
* confidence
* warmth
* adventure

Visual quality should feel editorial and premium without becoming impractical.

## Visual system

Primary palette:

* Midnight Navy: #071A2D
* Ocean Navy: #0B2742
* Warm Ivory: #FFF9EF
* Sand: #F1E3C8
* Antique Gold: #D4A64A
* Tea Green: #4F6F52
* Charcoal: #202321
* Mist: #DCE8EE

Target approximately 70% navy/dark surfaces and 30% warm ivory/sand surfaces.

Gold is an accent.

Never flood entire sections with gold.

## Typography

Use an editorial serif for:

* hero headings
* destinations
* itinerary day titles
* major totals
* major marketing statements

Use a modern sans-serif for:

* application UI
* forms
* navigation
* buttons
* descriptions
* maps
* prices
* utility text

Typography should carry much of the visual hierarchy.

## Layout

Prefer:

* strong asymmetrical compositions
* large deliberate photography
* map-led layouts
* editorial whitespace
* visual timelines
* route diagrams
* content hierarchy
* split-screen interfaces where appropriate

Avoid default card grids.

## Cartographic identity

Use subtle:

* contour lines
* map coordinates
* route paths
* destination markers
* thin connectors
* Sri Lanka silhouettes
* directional notation

These should support the interface rather than decorate every empty area.

## Photography

Use high-quality Sri Lankan travel imagery selectively.

Prioritise:

* scenic railway
* central highlands
* tea country
* Sigiriya
* Kandy
* Ella
* Galle
* southern coast
* wildlife
* historic architecture

Never tile a photographic background.

## Shape language

Most UI:

4–8px radius

Large image surfaces may use:

8–16px radius

Avoid excessive:

* pills
* circles
* floating cards
* heavy shadows

Prefer thin borders and whitespace.

## Anti-vibecode rules

Never default to:

* purple gradients
* neon glows
* glassmorphism everywhere
* blobs
* generic three-column feature grids
* dozens of rounded cards
* giant gradient headlines
* random floating metric cards
* emoji
* excessive badges
* generic AI illustrations
* fake analytics
* fake testimonials
* fake statistics

If a screen begins resembling a generic SaaS template, redesign it.

## UX principle

The interface must visually demonstrate WanderRoute's actual value:

Budget
→ Route
→ Itinerary
→ Costs
→ Map
→ Usable travel plan

Maps and budget information deserve high visual prominence.

## Copy

Use straightforward traveller language.

Good:

* Plan your Sri Lanka journey
* Set your budget
* Build my route
* Your itinerary
* See where your budget goes
* Explore nearby
* Download your travel plan

Avoid:

* algorithmic journey
* digital broadsheet
* curate your expedition
* initiate expedition
* revolutionise
* unleash
* AI-powered everywhere

## Responsiveness

Mobile is not a stacked desktop page.

Design intentional mobile interactions:

* bottom navigation
* sticky primary actions
* horizontally scrolling day navigation
* bottom sheets for maps
* collapsed summaries
* large touch targets

## Maps

Real Leaflet maps remain functional.

Improve their surrounding interface and marker/route presentation.

Never replace functional maps with static decorative images.

## Final quality test

Ask:

“Could this interface obviously belong to another AI startup if the WanderRoute logo disappeared?”

If yes, it is not distinctive enough.

Make the design more specific to Sri Lanka, travel routing and real-budget planning.
